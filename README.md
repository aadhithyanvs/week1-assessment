# Week 1 Python and Data Engineering Assessment

## Project Overview
This project covers Python programming, API handling, NumPy, Pandas, data cleaning, data analysis, and visualisation.

## Setup Instructions
1. Clone the repository.
2. Create a virtual environment: `python -m venv .venv`
3. Activate it: `.venv\Scripts\activate`
4. Install dependencies: `pip install -r requirements.txt`
5. Run the scripts and open the notebook in Jupyter.

## Key Findings
1. Employee data contains eight original records.
2. Missing salary values were filled using the median.
3. Duplicate employee records were removed.
4. IT has the highest employee headcount.
5. Marketing is the department without employees.
